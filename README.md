# Slay the Magic

Minecraft Java Edition 1.20.1（Forge 47.4.10）向けの Modpack です。Prism Launcher で遊ぶことを前提にしています。

- 配布ページ：https://akamatsu-first.github.io/Slay_the_Magic/
- Slay the MagicのZIPファイルのダウンロード：[Releases](https://github.com/Akamatsu-First/Slay_the_Magic/releases)
- Prism Launcherダウンロードページ：https://prismlauncher.org/

## ゲーム開始までの流れ

**以下の手順を踏まないと、ゲーム開始時もしくはネザー到達時にワールドがクラッシュします。必ず以下の1〜7の手順を行うようにしてください。**

1. 上記URLより、Slay the MagicのZIPファイルとPrism Launcherをダウンロードする。ZIPファイルは解凍しなくてよい。
2. Prism Launcherを開いたら右クリック→「起動構成の作成」を選択。
3. 画面左側の「インポート」を選択→右側に現れる「参照」をクリック→Slay the MagicのZIPファイルを開く。Modのダウンロードを手動で求める画面が出た場合は、その表示に従う。
4. Prism Launcherのホーム画面にSlay the Magicの起動構成が現れるので、それを右クリック→「フォルダ」を選択。
5. 「minecraft」→「stm_patcher」をダブルクリック。
6. **「apply_patches.bat」をダブルクリック。黒い画面に「All done」と出たら成功。**
何かキーを押すと画面が閉じる。
8. Prism Launcherのホーム画面に戻り、ゲームを起動する。初めて起動するときは、Minecraftを購入したMicrosoftアカウントでのログインを求められる。

**MacOSやLinuxでもこのゲームを遊べますが、「apply_patches.bat」を動作させるために、事前にPowerShell 7をダウンロードする必要があります。**
詳しい導入の手順、注意事項・利用規約、クレジット・ライセンスは、配布ページをご覧ください。

## ゲーム開始後の留意点
**このゲームは非常に高難易度となっております**。
戦闘や探索で得られた物が定期的に失われるストレスに耐えられる、ないしはそれを楽しいと思える人がこのゲームのターゲット層になっております。予めご了承下さい。

ほぼ全てのバイオームの気温と水温をconfigによりかなり極端にしております。よって初期リスポーン地点が高熱地帯、氷雪地帯、または小さな島の場合、ほとんどの確率で死に戻りを繰り返すのみの詰みワールドになります。なので平原が初期リスポーン地点になっているシード値を引き当てるまでリセマラを繰り返すか、平原スタートになっている以下のシード値をご活用下さい。
